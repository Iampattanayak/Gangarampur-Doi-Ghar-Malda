# Gangarampur Doi Ghar - Digital Catalog

A modern, responsive web application for **Gangarampur Doi Ghar**, a traditional sweets and curd shop in Malda. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🎯 Features

- **Modern UI** - Clean, fast, and intuitive design
- **Responsive Design** - Perfect experience on mobile, tablet, and desktop
- **Product Showcase** - Beautiful cards displaying signature doi, ghee, ice creams, chocolates, and beverages
- **Best Sellers Section** - Horizontal scrolling showcase of signature items
- **Category Navigation** - Smooth scrolling to different product sections
- **Search Functionality** - Quick product search with real-time filtering
- **Call-to-Order** - Direct phone call integration for easy ordering
- **Store Location** - Embedded Google Maps for easy navigation
- **Smooth Animations** - Powered by Framer Motion for delightful interactions

## 🛠️ Tech Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Fonts:** Inter

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd shop
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173` (or the port shown in terminal)

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.

### Preview Production Build

```bash
npm run preview
```

- Visual hierarchy emphasizing key products
