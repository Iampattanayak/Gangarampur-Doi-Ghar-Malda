# Product Images Guide

This guide tells you which image to place in each folder and what to name it.

## Image Requirements
- **Format**: JPG, PNG, or WEBP
- **Size**: Recommended 800x800px (square)
- **Quality**: Clear product photos with white or transparent background
- **Naming**: Use the exact filenames listed below (lowercase, hyphens for spaces)

## Quick Tips
1. **Placeholder images**: If you don't have a specific product image, use a similar one temporarily
2. **Consistent style**: Try to keep all images in a similar style (same background, lighting)
3. **File size**: Keep images under 200KB each for faster loading
4. **Testing**: After adding images, refresh the browser to see them appear

## What happens next?
Once you've added the images to the folders above, I'll update the code to automatically display them instead of emojis!
